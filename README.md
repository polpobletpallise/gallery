# Gallery

A local-first desktop gallery for browsing photos, videos, and audio files.

## Run

Install dependencies and start the development app:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Privacy

Gallery processes selected media folders locally. It does not collect or transmit your media or personal data; folder selections and preferences are stored on your device.
